Invoice Application - User Readme

How to start

1. Copy the full project folder to a writable location on your computer.
   Recommended:
   - Desktop
   - Documents
   - D drive or another normal folder

2. Do not run the app using file:// or by opening HTML files directly.

3. Start the application by double-clicking:
   Launch Shaker.cmd

4. The app will open in your browser.


Important files and folders

- Launch Shaker.cmd
  Main launcher for the application

- data\storage.json
  This is the live application data file

- js\
- css\
- assets\
- scripts\
  These folders are required for the app to work


Data storage

- Your working data is stored in:
  data\storage.json

- This includes invoices, customers, items, vendors, purchase orders, and settings.

- Keep this file safe.


Backup and restore

- Use the in-app Backup Data button regularly.
- Store backup files in a safe location outside the app folder if possible.
- Use Restore Data inside the app when you want to restore a previous backup.


If you move the project folder

- Copy the complete folder, not only individual files.
- Keep the data folder together with the app.


If the app does not open

1. Make sure you started it using Launch Shaker.cmd
2. Do not open app.html directly
3. Make sure the folder is in a writable location


Recommended user practice

- Always open the app using Launch Shaker.cmd
- Take backups before major changes
- Do not delete files inside js, css, assets, scripts, or data


Support note

If the app behaves unexpectedly, first back up your data and then contact the project owner/support person.
